WHAT THIS REPOSITORY IS
-----------------------
The recipe layer: bundle manifests, the catalogue excerpt, and the export tool
that projects them out of the private composition source. This is the wave
carrier - recipes go public here wave by wave, not all at once.

WHY THIS FILE EXISTS
--------------------
Until a wave is released, every form of publication is barred: GitHub
visibility public, public forks or mirrors, registry and marketplace entries,
package publishes, public websites carrying this content.

Editing the repository is explicitly allowed. This is a publication lock, not
a work lock.

WHO MAY LIFT THIS GATE
----------------------
This file carries explicit release conditions, so under LOCK-SYSTEM.md an
agent may delete it once ALL THREE are demonstrably met - with a documented
record of which condition was met how. Condition 3 is a user decision by
definition, so in practice the user is always involved.

What an agent must never do: change the repository visibility because the work
looks finished. Visibility is changed by the user (VISIBILITY-POLICY.md,
closing line).
